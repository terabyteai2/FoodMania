Here is the summary of the Terafoods (TF) POS Design System, formatted for scannability and compliance verification.
System Overview & Target

    Target Hardware: Budget Android devices (MediaTek Helio G35, 3–4 GB RAM). Requires aggressive UI performance optimization.

    Localization: Bilingual English (EN) / Bangla (BN) handled automatically via Tf* primitives based on the active app locale.

    Source of Truth: All UI surfaces must use tf_design_system.dart + app_theme.dart. Hand-rolled equivalents or parallel widget sets are strictly forbidden.

1. Design Tokens
Color Palette (PosColors.*)

Hex literals (Color(0xFF...)) are completely banned in feature code.
Token	Hex	Use Case
primary	#F5C127	Brand CTAs, focus accents, primary buttons
primaryDark / slate	#1C1A17	Headings, body text, dark surfaces, text on primary buttons
background	#F7F4EE	Scaffold background (warm off-white to reduce glare)

primarySoft / primaryWash	#FEF1C5 / #FFF9E0	Brand-tinted soft surfaces
Typography & Bi-directional Text

    Families: English (Inter) and Bangla (Noto Sans Bengali) must always be set dynamically via tfFontFamily(context). String literals are banned.

    Weights: Only two legal weights exist. Visual emphasis must come from color or size contrast rather than weight:

        FontWeight.w400 (Body, helpers, descriptions)

        FontWeight.w500 (Headings, buttons, labels, emphasis)

        Weights w600 through w900 are banned.

    Bi-directional Primitives: Raw Text(...) is banned.

        TfText(string) automatically converts Western digits to Bengali numerals (০–৯) in the BN locale.

        TfMoney(amount) automatically formats currency with the Taka symbol (৳) using the active locale.

Shapes, Spacing & Borders

    Radii (PosRadii): Only values of 8 (xs), 12 (sm/md/lg/xl), and 999 (pill) are permitted.

        Exception: circular(2) is permitted only for thin status lines or accent stripes (e.g., TfRail).

    Borders: Fixed at 0.5px width using PosColors.line or lineStrong. Only one border layer per surface is allowed.

    Padding Conventions: Screen edges must use fromLTRB(16, 14, 16, 14). Card content uses fromLTRB(14, 12, 14, 12).

2. Hard Performance Rules (GPU-Friendly)

To protect budget MediaTek hardware from frame drops, the following are strictly enforced:

    blurRadius must be ≤8 anywhere on the screen.

    boxShadow lists can have at most one entry.

    BackdropFilter and ImageFilter.blur are completely banned.

    surfaceTintColor must be set to Colors.transparent across all surfaces to skip Material 3 blending logic.
